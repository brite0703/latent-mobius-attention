# Publication scope

Included: byte-preserved author-origin study Python sources matching the original public 14 manifest; exact original requirements; project-original native N20 captures and table formatter; newly written code/metadata check tools, command plans, environment/data-acquisition instructions and result crosswalks.

Excluded from this new payload: manuscriptPDF/TeX, reviewer/editor responses and letters, biographies/photos, private review/history documents, private input/aggregate/caption snapshots, checkpoints/arrays, credentials, third-party datasets and new copies of historical evidence archives. Existing public history/release assets remain unchanged.

Original capture paths and fail-closed scientific guards are retained. Private workspace provisioning helpers and relocation/materialization adapters are not promoted as a public turnkey workflow; some bind omitted private history/metadata. The source mirror is reviewable code and explicitly scoped entry documentation, not a complete all-grid retraining or upstream-reconstruction system.
