Bounded public entry update, 7 October 2026, based on source commit 50472812494054d3c8ea03efe256f3b3b2e47bdf. ## Bounded entry checks

~~~bash
python3 -I -B tools/check_sources.py
python3 -I -B tools/n20_entry.py fp32
python3 -I -B tools/n20_entry.py fp32 --import-only
python3 -I -B tools/fixed_report_entry.py complete
python3 -I -B tools/table_entry.py
python3 -I -B tests/test_public_entrypoints.py
~~~

The source checker inspects bytes and syntax. Default entry modes print plans using only the standard library. N20 import-only checks an explicit AST definition view of public, hash-bound code; it omits three import-time size/seed calls and blocks scientific main, data loads, model construction, forward/backward and CUDA initialization. It does not run an experiment. Fixed-report preflight requires explicit external evidence and preserves the original status gates. Table preflight/export requires explicit external metadata and retained summaries. [Commands and input boundaries](docs/COMMANDS.md) describe each mode.
